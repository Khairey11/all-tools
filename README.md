# OptiPik - Premium Image Compressor

A modern, high-performance web-based image compressor that runs entirely in the browser. Built with React, Vite, and TailwindCSS.

## Features
- 🚀 **Client-side Compression**: No server uploads (Privacy focused).
- 🎨 **Premium UI**: Modern dark mode with motion effects.
- 📉 **Real-time Preview**: Compare original and compressed images instantly.
- 🎛️ **Customizable**: Adjust quality, max width, and max size.

## Prerequisites
You need **Node.js** installed on your computer to run this application.
[Download Node.js here](https://nodejs.org/)

## Getting Started

1. **Install Dependencies**
   Open your terminal in this folder and run:
   ```bash
   npm install
   ```
   *(If npm is not found, please install Node.js first)*

2. **Run Development Server**
   Start the local server:
   ```bash
   npm run dev
   ```

3. **Open App**
   Open your browser and navigate to the URL shown in the terminal (usually `http://localhost:5173`).

## Building for Production
To create a production-ready build:
```bash
npm run build
```
The files will be generated in the `dist` folder, ready for hosting.

## Hosting
You can host the `dist` folder on any static file host:
- Vercel
- Netlify
- GitHub Pages
